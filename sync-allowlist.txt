# sync-allowlist.txt — what is allowed to live inside each recursively-synced
# directory from sync-manifest.txt. capture.ps1 validates the LIVE folders
# against this BEFORE copying and aborts the whole capture on any unlisted file.
#
# WHY: this repo backs up GLOBAL agent configuration only. Project/session
# files (memory dumps, session wrap-ups, project notes) belong in their
# project's own repo — an unlisted file here is treated as a stray, never
# silently synced. (A project session note swept into ai-instructions/ is
# exactly how a project's payments session-note once polluted this repo.)
#
# Format: <repo-relative-dir> | <home-relative glob>      (# comments allowed)
#   *  matches within one path segment; ** crosses segments.
# Doc-bearing dirs are enumerated file-by-file ON PURPOSE — adding a new doc
# means adding a line here. That is the guard working, not friction.
